## Round 3 — 2026-08-01

**Findings**:
1. *(accept-worthy)* `core.py` — the 3-backtick fence around quoted PR text can be closed by
   the payload itself. Upstream `format_pr_feedback` interpolates comment bodies verbatim and
   indents only the first line, so a Copilot ```` ```suggestion ```` block emits a bare
   3-backtick line at column 0, terminating the outer fence and letting the rest of an
   untrusted comment escape the data framing.
2. *(accept-worthy)* `core.py` — `format_pr_feedback` returns the literal
   `"Reviews: clean (0 unresolved threads, 0 alerts)"` rather than `None`/empty, so the
   truthiness guard passes on clean PRs and the "treat each as a finding" note is threaded
   every round against a payload saying the opposite — inviting a fabricated finding.

Re-verified clean: exit-code precedence 2→1→0, `pr_feedback_text` None-guarding, plan lane
skipping the GitHub call, shim re-export surface, round-1 docs vs `_exit_code`, per-round
freshness, and that the un-wrapped `collect_branch_status` call cannot raise into a round.

**Decisions**:
- 1 — **Accept** as proposed (fence an embedded block cannot close).
- 2 — **Accept the defect, reject the proposed fix.** Prefix-matching `"Reviews: clean"`
  couples to an upstream string with no exported constant and would silently degrade if
  upstream reworded. Reworded the note to be accurate in both cases instead — same outcome,
  no coupling.

**Changes** (`src/mcp_coder/workflows/review/core.py`, `tests/workflows/review/test_core.py`,
`test_core_after_steps.py`):
- `_QUOTE_FENCE` = 5 backticks (CommonMark: an N-backtick fence closes only on ≥N), applied
  at both sites.
- Reviewer note reworded to describe the block as the current PR review feedback section
  which may report reviews are clean; supervisor heading `## Open PR review feedback` →
  `## PR review feedback`; `_pr_feedback_note` docstring corrected.
- Shared framing + fence hoisted into `_quote_pr_feedback` (the two sites were byte-identical).
- Tests: fence assertions updated; new cases for an embedded ```` ```suggestion ```` payload
  round-tripping inside the outer fence, and for the clean payload not asserting that
  feedback was posted.

**Verification**: pylint, mypy, ruff, pytest (4721 passed / 2 skipped) — all pass.

**Status**: committed.
