### Implementation

`TASKS_JSON_TEMPLATE` becomes (note the doubled braces required by `str.format`):

```python
TASKS_JSON_TEMPLATE = """{{
    "version": "2.0.0",
    "tasks": [
        {{
            "label": "VSCodeClaude Startup",
            "type": "shell",
            "command": "{script_path}",
            "presentation": {{
                "reveal": "always",
                "panel": "new",
                "focus": false
            }},
            "runOptions": {{
                "runOn": "folderOpen"
            }},
            "problemMatcher": []
        }}
    ]
}}
"""
```

Changes versus the current template: the entire `"Open Status File"` object is deleted, and
`"focus": true` → `"focus": false`. Everything else is byte-identical.

Also update the module docstring reference only if it names the removed task (it does not
today — it just lists `TASKS_JSON_TEMPLATE`).

## ALGORITHM (guard test)

```
create_vscode_task(tmp_path, tmp_path / ".vscodeclaude_start.bat")
tasks = json.loads((tmp_path / ".vscode" / "tasks.json").read_text(encoding="utf-8"))["tasks"]
auto = [t for t in tasks if t.get("runOptions", {}).get("runOn") == "folderOpen"]
assert auto                                    # the guard must not pass vacuously
for task in auto:
    assert task["command"] != "code"
    assert "code" not in task.get("args", [])
```
